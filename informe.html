EstudianteBrando Daniel Cabrera Bonilla

Repositorio usadoreqres.in/api/users
HerramientaPostman (Desktop App)

A continuación se documentan las pruebas realizadas con Postman sobre el recurso /api/users del repositorio https://reqres.in, cubriendo los cuatro métodos HTTP solicitados: GET, POST, PUT y DELETE.

1. Método GET — Listar usuarios

Petición: GET https://reqres.in/api/users?page=2
Resultado: 200 OK — 618 ms — devuelve el listado de usuarios de la página 2.

2. Método POST — Crear usuario

Petición: POST https://reqres.in/api/users
Header: Content-Type: application/json
Resultado: 201 Created — 426 ms — se crea el recurso con id generado automáticamente.

Body JSON enviado:

{
  "name": "morpheus",
  "job": "leader"
}

3. Método PUT — Actualizar usuario

Petición: PUT https://reqres.in/api/users/2
Header: Content-Type: application/json
Resultado: 200 OK — 420 ms — se actualiza el campo job del usuario con id=2.

Body JSON enviado:

{
  "name": "morpheus",
  "job": "zion resident"
}

4. Método DELETE — Eliminar usuario

Petición: DELETE https://reqres.in/api/users/2
Resultado: 204 No Content — 441 ms — el recurso se elimina sin devolver contenido en el body.

Conclusiones

Postman permitió comprobar de forma práctica el comportamiento de los cuatro métodos HTTP principales sobre una API RESTful real. Se verificó que GET y PUT devuelven 200 OK, POST devuelve 201 Created junto con el recurso creado, y DELETE devuelve 204 No Content sin body, confirmando el comportamiento idempotente esperado en PUT y DELETE.
